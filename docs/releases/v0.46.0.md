# Kagi 0.46.0 — Nagi themes and adaptable compact layouts

## Nagi Light / Nagi Dark

Two Apple-derived themes reduce competing colours without washing out the interface. Neutral chrome, three blue/green/amber Graph lane colours and clearer dark-theme highlights keep history readable. Diff additions and deletions retain their semantic colours. Both languages use the names **Nagi Light** and **Nagi Dark**; existing themes and the default remain unchanged.

## A compact threshold that follows text size

**Settings → Appearance → Compact layout threshold** lets you choose **40–160rem**, in whole-rem steps. The default is **70rem**, approximately **1008 logical pixels at 100% UI zoom**. The setting shows its current logical-pixel equivalent, applies immediately and survives restart.

Larger UI text now makes the compact layout activate at a wider window width. OS display scaling is not counted twice. For example, **80rem** switches a 1080-logical-pixel-wide window to compact at 100% zoom. The existing compact and wide presentations continue to share commit inputs, drafts and session state.

## Better-fitting commit and file views

- Expand or collapse individual directories in a commit's changed-file Tree, in both the wide Inspector and compact Changes view. Nested disclosure survives parent toggles and Path/Tree switches; keyboard navigation excludes collapsed descendants. Disclosure motion respects Reduce Motion.
- The compact Commit popup fits short drafts instead of leaving empty space below the Commit button. Longer drafts retain bounded input space and the existing Commit controls.
- Keyboard navigation reveals Settings steppers and switches at enlarged text sizes without pulling subsequent manual scrolling back to the focused control. Smart Commit still requires explicit consent before it can be enabled.
- PR Peek exposes fetched heads outside the loaded Graph in compact Changes; its navigator hands clicks to the context menu without opening the PR behind it.

## Distribution and scope

macOS remains arm64-only and ad-hoc signed, without Developer ID notarization. Linux and Windows packages retain the existing distribution formats. This release does not complete the remaining upstream dependency migration or unrelated open issues.

Existing limitations from [0.45.0](https://github.com/TomiXRM/kagi/releases/tag/v0.45.0) still apply. In particular, save Editor buffers before macOS Dock Quit, logout or shutdown: those OS termination paths still lack the unsaved-buffer veto (#1614). The remaining GPUI/component upstream cutover is not included (#1479-S6).
