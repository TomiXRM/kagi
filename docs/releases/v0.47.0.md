# Kagi 0.47.0 — PDF reading and quieter Git operations

## Read PDFs in Editor and commit history

Editor now displays PDFs as continuously scrollable, read-only pages. Git Graph can show the previous and selected PDF versions side by side, including renamed files and explicit added/deleted sides.

- Switch comparisons between **independent and synchronized scrolling**. Either side can lead; synchronization follows page-relative positions without changing zoom.
- Use **Fit Width**, page navigation, keyboard scrolling and draggable scrollbars. Zoom changes preserve the reading position.
- Preview-first rendering, neighboring-page prefetch and a bounded reusable image cache reduce scrolling stalls. Existing images remain visible during refinement.
- Hide or restore Editor's supplementary Diff/History pane with its header control, the View menu, command palette or **Cmd+Option+E**, without losing document state.

PDF comparison shows both documents; it does **not** compute or highlight their differences. Complex uncached pages can still require initial rendering time. Password entry and universal font fidelity are not supported; malformed and password-protected documents show errors.

## Pull and Push without unnecessary interruption

A normal safe Pull now runs without an extra confirmation or automatic stash. Kagi fetches before deciding and preserves unrelated staged, unstaged and untracked changes.

When incoming changes would overwrite local work, Kagi names the affected paths and offers **Review changes**, **Stash & Pull**, or **Cancel**. Conflicting committed histories instead lead to Merge review and Conflict Mode: stashing is not presented as a cure for a history conflict.

Confirming with Enter closes the Pull dialog immediately, including while the operation is still running. Repeated Return does not start another Pull. Ordinary safe Push also runs without an extra dialog. Preflight checks, repository ownership, verification and durable Operation Log records remain in place; newly detected risk is refused rather than silently expanding the approved operation. SSH remote Pull retains its explicit confirmation.

## Markdown and keyboard improvements

- Choose whether newly opened Markdown files start in **Preview or Source** in Settings; Preview is the default. Existing buffers keep their current mode and unsaved edits.
- Markdown Preview immediately reflects unsaved edits without implicitly saving or losing Undo history. Its mode switch is keyboard-accessible.
- Mermaid diagrams respect UI/display scaling, fit narrow panes and show readable failure explanations.
- **Cmd+Shift+C** copies the selected commit's local branch name while Graph has focus. With no selected local branch, the clipboard is left unchanged. Text and terminal copy shortcuts retain ownership.
- Editor Save/Undo/Redo no longer fall through to unrelated Git actions during PDF classification, preview or background refresh.

## Clearer compact layouts and navigation

- The PR sidebar recovers clicks after horizontal gestures. Its companion-pane control is visibly a toggle and is named **Graph**; sidebar visibility lives in persistent leading chrome.
- Long confirmation notes and operation-queue history stay in bounded scroll areas. Cancel remains reachable when action labels wrap.
- Compact Changes opens staged/unstaged diffs directly, and newer commit drafts survive completion of an older commit.
- Switching Unified/Split diff preserves the reading position. PR diff redraws reuse review-thread mappings, and squash-merge connectors use nearby Graph lanes.
- Additional fixes preserve PDF source identity, staged renames, conflict stages, focus retirement and bounded reads, and improve confirmation contrast and recovery instructions.

## Downloads and platform notes

- **macOS Apple Silicon:** DMG or installer tar. The application is ad-hoc signed, not Developer ID signed or notarized; Gatekeeper may require the documented first-launch steps.
- **Linux x86_64 / aarch64:** tar, AppImage zip and Debian package. Supported host system libraries are still required.
- **Windows x86_64:** zip.
- Platform-specific SHA256SUMS files accompany the packages.

For an isolated version-pinned installation, use the repository's `install.sh` with `--version v0.47.0`; `--prefix` and `--no-modify-path` are supported on macOS/Linux.
